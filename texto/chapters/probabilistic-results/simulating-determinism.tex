In this section we show how to simulate a deterministic transformer with a probabilistic one.
Thus, we obtain the following theorem.

\begin{theorem}[]
    $\CoTtndn \subseteq \RCoTtndn$ for all $T(\cdot)$ and $d(\cdot)$
\end{theorem}

Let $\TF$ be a deterministic transformer.
We construct a probabilistic transformer $\TF'$ that accepts the same words in the same number of steps of $\CoT$ and with the same embedding size.

As per Section \ref{det-norm}, we assume $\TF$ to be normalized.
We define $\TF'$ exactly as $\TF$, except for the token selector which by definition is the probabilistic.
Now, $\TF$ and $\TF'$ behave exactly the same.
Since $\TF$ is normalized, the distribution $p$ generated in every step satisfies the property that there exists $\sigma \in \Sigma$ such that:
%
\[
    p(\tau) =  \begin{cases}
        1 & \text{ if } \tau = \sigma \\
        0 & \text{ otherwise} \\
    \end{cases}
\]
%
Then, sampling this distribution $p$ always returns the token $\sigma$, the same token that $\argmax$ would return.
Next, the deterministic token selector and the probabilistic token selector behave the same.
Thus, for all $i$ and $\alpha$, $\TF^i(\alpha) = \TF'^i(\alpha)$.
In particular, this means that $\TF^*(\alpha) = \TF'^*(\alpha)$.
Therefore, $\TF$ and $\TF'$ accept the same words (and in the same number of steps).
By construction, the embedding size of $\TF$ and $\TF'$ is the same.

\medskip

Finally, let $\gL \in \CoTtndn$.
Then, there is a family of deterministic transformers $\{\TF_n\}_{n \in \mathbb{N}}$ of embedding size $O(d(n))$ that after $O(T(n))$ steps of $\CoT$ computes $\gL$.

We define the family $\{\TF'_n\}_{n \in \mathbb{N}}$ of probabilistic transformers by applying the construction just presented to each $\TF_n$.
Then, the transformers in $\{\TF'_n\}_{n \in \mathbb{N}}$ have embedding size $O(d(n))$ and compute $\gL$ using $O(T(n))$ steps of $\CoT$.

Therefore, $\gL \in \RCoTtndn$, and consequently $\CoTtndn \subseteq \RCoTtndn$.
