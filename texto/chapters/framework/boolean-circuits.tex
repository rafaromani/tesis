Lista de cosas que voy referenciando:

\begin{itemize}
    \item suma de k números está en $\AC^0$ para k fijo y precision fija
    \item indexar diccionario de tamaño fijo está en $AC^0$
    \item def $\SIZE$, $\AC^0$, $\TC^0$
    \item def $\RAC^0$ como $\AC^0$ pero con una cantidad poly de bits random
    \item $\RAC^0[1]$, es $\AC^0$ con una cantidad constante de bits
    \item En general uso $\RAC^0[f(n)]$ para un circuito en $\RAC^0$ con $O(f(n))$ bits aleatorios.
    \item $\RAC^0[f(n)] = \AC^0$ cuando $f(n) \in O(\log(\log(n)))$ decir que es un teorema y ponerle \label{const-random-in-ac0}
    \item majority not in ac0
    \item majority (y cualquier otra operación) en un arreglo de $\log(n)$ bits se puede hacer en $AC^0$ (simplemente enumeras todos los posibles inputs)
    \item $\MAJORITY_pr$ con $pr > 1/2$ se puede hacer en ac0 (https://www.ccs.neu.edu/home/viola/papers/BPvsE.pdf)
    \item $\RSIZE$
    \item $\Rppoly$
    \item Teo $\ppoly$ restringido a uniforme es $\Ptime$ \label{uppoly-equals-p}
    \item Teo $\Rppoly$ restringido a uniforme es $\BPP$ \label{urppoly-equals-bpp}
    \item Adleman's theorem $\BPP \subseteq \ppoly$ \label{adleman}
\end{itemize}
