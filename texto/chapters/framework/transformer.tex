In this work we are going to analyze transformers as language recognizers.
A transformer is a machine that works over an alphabet $\Sigma$.
It has only one tape from where it reads the input and in an autoregressive way writes in it more tokens.
There are two distinguished tokens called \textbf{decision symbols}.
Once the transformer writes one of those, it halts.
We say that a transformer accepts a word if when it halts the decision symbol printed is the accepting one ($\qaccept$).
Correspondingly, a transformer rejects a word if the decision symbol printed is the rejecting one ($\qreject$).

In each step the transformer maps the content of the tape to a probability distribution over the alphabet.
Depending on this distribution the transformer prints the next token.
The transformer iterates this process until it halts.
These iterations are called \textbf{chain of thought}.

The process of generating the next token consists of two separated steps.
First a probability distribution over the alphabet for the next token is computed by a process called distribution generation.
After that, it is necessary to decide the specific token by a process called token selection.
These two algorithms together is what defines the transformer.
During this work we will analyze and compare two different options for token selection.

\medskip

For a more realistic analysis of the transformers, we don't allow an infinite tape.
The transformers studied in this work, for each input size $n$, will have a tape of size $\budget(n) + n$.
It's important to remark that, since in every step of the transformer a symbol is written, the maximum number of steps a transformer can do for an input of length $n$ is $\budget(n)$.

\medskip

The process of distribution generation is dependent on many parameters.
These parameters, in the real models, are the ones calculated during the training.
We refer to them as $\theta$.
We consider the parameters as part of the definition of a transformer.

We note $\TF(\alpha)$ to the token outputted by one step of the transformer $\TF$ when the tape content is $\alpha \in \Sigma^*$.
The autoregressive token generation is defined recursively. The token outputted after $i$ steps is $\TF^{i}(\alpha) := \TF^{i-1}(\alpha \TF(\alpha))$ with base case $\TF^1(\alpha) := \TF(\alpha)$.
In other words, the output of the $i$th step is $\sigma_{i} = \TF^{i}(\alpha) = \TF(\alpha\sigma_{1}\dots\sigma_{i-1})$ where $\sigma_j \in \Sigma$ for all $j$.

We note $\TF^*(\alpha)$ for the token written by the transformer when it halts, i.e. at the end of the computation, when the input is $\alpha$.
As was said before, the transformer only halts when it prints a decision symbol ($\qaccept$ or $\qreject$).
Therefore, $\TF^*(\alpha) \in \{\qaccept, \qreject\}$.

As stated before, the \textbf{distribution generation} is a mapping of the content of the tape to a probability distribution over $\Sigma$.
There are different algorithms for this process in the literature.
All the transformers considered in this work use the one presented by \cite{toyota}. 
This algorithm consists of four parts: a token embedding layer ($\TE$), a position encoding layer ($\PE$), an output linear layer ($\OUTPUT$), and a stack of $L$ identical decoder layers, where $L$ is also called the depth of the model. 
Each decoder layer has two sub-layers: a multi-head self-attention layer ($\ATTN$) and a position-wise fully-connected feed-forward network ($\FF$). 
Each part and layer has its own trainable parameters.
Then, we can define the distribution generation algorithm by its parameters $\theta = \{\theta_\TE, \theta_\PE, \{\theta_\ATTN^{l}, \theta_\FF^{l}\}_{l=0}^{L-1}, \theta_\OUTPUT\}$.
The algorithm works over vectors of certain dimension $d$.
Let's define each component.

%Each part
\textbf{Token Embedding:} It's a mapping from $\Sigma$ to vectors in $\Rd$. This mapping is defined by $\theta_{\TE} \in \mathbb{R}^{d \times | \Sigma |}$. For all $\sigma \in \Sigma$, we note $\theta_{\TE}(\sigma) \in \mathbb{R}^d$ to the mapping of token $\sigma$.

\textbf{Position Encoding:} It's a mapping from the positions of the tape to vectors in $\Rd$. This mapping is defined by $\theta_{\PE} \in \mathbb{R}^{d \times \budget(n) + n}$. For all position of the tape $1 \leq i \leq \budget(n) + n$ we note $\theta_{\PE}(i) \in \Rd$ to the mapping of position $i$.

\textbf{Self Attention Layer: } It's a mapping from $(\Rd)^a$ to $(\Rd)^a$. Given parameters $\theta_{\ATTN} = (W_Q, W_K , W_V , W_O) \in \mathbb{R}^{d \times d} \times \mathbb{R}^{d \times d} \times \mathbb{R}^{d \times d} \times \mathbb{R}^{d \times d}$, the layer it's defined by the algorithm \ref{alg:def_attn}. This layer is defined only as a single head attention layer because we can simulate 1 multi-head attention layer with any constantly many heads with multiple single-head attention layers. \cite{cookbook}

\begin{algorithm}
\caption{Causal Self-Attention, $\ATTN$}\label{alg:def_attn}
\begin{algorithmic}[1]
\Require  Parameter $\theta_\ATTN = (W_Q,W_K,W_V,W_O)$, Input embedding $h= (h_1,\ldots, h_a)\in\Rd \times \dots \times \Rd$.
\Ensure Output embedding $h'= (h'_1,\ldots, h'_a) := \ATTN_{\theta_\ATTN}(h_1,\ldots, h_a)$.
\State $q_i := W_Q  h_i, \; k_i := W_K h_i, \; v_i := W_V h_i, \; \forall i\in[1, \dots, a]$
\State $s_i := \softmax (\langle q_i, k_1 \rangle, \ldots, \langle q_i, k_i\rangle) \| (0,\ldots, 0) $
\State $h'_i := W_O \sum_{j=1}^a (s_i)_j v_j$
\end{algorithmic}
\end{algorithm}

\textbf{Feed Forward Network: } It's a mapping from $\Rd$ to $\Rd$. Given $\theta_{\FF} = (W_1 , b_1 , W_2 , b_2) \in \mathbb{R}^{d \times d} \times \Rd \times \mathbb{R}^{d \times d} \times \Rd$, it's defined as $\FF_{\theta_\FF}(h) := W_2 \; \relu(W_1 h + b1 ) + b2$, where $\relu: \mathbb{R}^d \to \mathbb{R}^d$ replaces each position $x_i$ by $\text{max}(0, x_i)$.

\textbf{Output Layer: } It's a mapping from $\Rd$ to a probability distribution over $\Sigma$. Given $\theta_{\OUTPUT} \in \mathbb{R}^{| \Sigma | \times d}$, it's defined as $\OUTPUT_{\theta_\OUTPUT}(h) := \softmax(\theta_\OUTPUT h)$.


All these parts come together for the distribution generator process in the algorithm \ref{alg:def_p_gen}.

\begin{algorithm}
\caption{Distribution generator}\label{alg:def_p_gen}
\begin{algorithmic}[1]
\Require   Transformer parameter $\theta = (\theta_\TE, \theta_\PE, \{\theta_\ATTN^{l}, \theta_\FF^{l}\}_{l=0}^{L-1}, \theta_\OUTPUT)$ and tokens of the tape $\alpha \in \Sigma^*$.
\Ensure Output distribution $p_\theta(\cdot | \alpha)$.
\State $h^{(0)}_i \gets \theta_\TE(\alpha_i) + \theta_\PE(i), \; \forall 1 \leq i \leq |\alpha|$
\For{$l = 0,\ldots,L-1$}
\State	$( h^{(l+0.5)}_1,\ldots, h^{(l+0.5)}_{|\alpha|}) \gets (h^{(l)}_1,\ldots, h^{(l)}_{|\alpha|}) +\ATTN_{\theta^{(l)}_\ATTN}(h^{(l)}_1,\ldots, h^{(l)}_{|\alpha|}) $
\State  $ h^{(l+1)}_i \gets  h^{(l+0.5)}_i + \FF_{\theta^{(l)}_\FF}(h^{(l+0.5)}_i)$, $\forall 1 \leq i \leq |\alpha|$
\EndFor
\State $p_\theta(\cdot| \alpha) \gets  \OUTPUT_{\theta_\OUTPUT}(h^{(L)}_{|\alpha|})$
\end{algorithmic}
\end{algorithm}

The $\OUTPUT$ layer and the $\ATTN$ layer uses a $\softmax$ function.
It is defined from $\mathbb{R}^n$ to $\mathbb{R}^n$ for all $n$ as $\softmax(x)_i = exp(x_i) / \sum_{j=1}^n exp(x_j)$.

                % Def token selection %

The second component of a transformer is the \textbf{token selector}.
This algorithm consumes the probability distribution computed by the distribution generator and returns a token.

Lets $p : \Sigma \to [0,1]$ be the output of the distribution generator.
In this work we will study two selectors.
The first one always returns the token with the largest probability ($\argmax$ over $p$, where $p$ is the output of the distribution generator).
The other, works non-deterministically.
It returns the token $\sigma \in \Sigma$ with probability $p(\sigma)$.
